# How to improve at basketball - 농구 스킬 향상

## 사용자와 목표
- 사용자 : 농구를 입문하거나 실력향상을 목표로하는 사람
- 목표 : 기본적인 훈련 루틴을 정하고, 향상을 위한 연습을 한다.

## 사용자의 흐름
1. 녹화 활용에 동의하고 '훈련 설정 시작하기'를 누른다.
2. 훈련 제목을 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 훈련 시간을 선택하고 필요하면 질의 응답을 포함한다.
4. 제목, 시간, 질의응답 설정을 확인하고 수정하거나 완료한다.
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다.

## 인터랙션 시나리오
1. 시작과 녹화 활용 안내
- 행동, 이벤트 : 기존 동의 체크박스를 선택하고 '훈련 설정 시작하기'를 클릭한다.
- 조건 : 녹화 및 영상게시 동의가 선택되었는가?
- 반응, 다음상태 : 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용목적을 설명하는 안내 팝업이 열린다.
                    팝업에서 '돌아가기'를 누르거나 Esc를 누르면 동의를 해제하고 시작 화면에 남는다.
                    '동의하고 설정 시작하기'를 누르면 제목 입력 화면을 연다.
2. 제목 입력
- 행동, 이벤트 : 제목을 적고 '훈련 조건 선택하기'를 클릭한다.
- 조건 : 앞뒤 공백을 지운 제목이 비어있는가?
- 반응, 다음상태 : 비어있으면 같은 화면에 오류를 표시, 입력창에 초점을 둔다.
                    값이 있으면 저장하고 조건 선택으로 이동한다.
3. 조건 선택
- 행동, 이벤트 : 훈련 시간을 바꾸거나 질의응답을 선택하고 '내용 확인하기'를 클릭한다.
- 조건 : 질의응답을 선택헀는가?
- 반응, 다음상태 : 선택했을 때만 질문 수를 보여준다, 선택하지 않았을 경우 미포함으로 표시한다.
4. 내용 확인
- 행동, 이벤트 : 제목, 시간, 질의 응답 내용을 읽고 '수정하기' 또는 '설정 완료하기'를 클릭한다.
- 조건 : 수정 or 완료
- 반응, 다음상태 : 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다.
                 완료하면 완료 안내로 이동한다.
5. 완료와 다시 설정
- 행동, 이벤트 : 완료 안내를 읽고 필요하면 '다시 설정하기'를 클릭한다.
- 반응, 다음상태 : 새 설정의 제목, 시간, 질의응답, 진행 상태를 초기화하고 제목 입력부터 다시 시작한다.
                이미 확인한 녹화 및 영상게시 동의와 다른 기능을 유지한다.

## 1. 7주차 대비 새로 추가된 기능
- 7주차의 '훈련 조건 설정 완료(Step 4)' 단계 이후, 설정한 조건으로 실제 훈련을 수행하며 진행률을 확인.
- 피드백을 기록/삭제할 수 있는 'Step 5: 실시간 훈련 진행 및 일지 작성 기능'을 추가.

## 2. 새 기능의 시나리오 (행동 → 조건 → 반응 → 다음 행동)
- 사용자 행동 : Step 4 완료 화면에서 '훈련 시작하기' 버튼 클릭 → Step 5 이동 후 기본기 드릴 체크, 훈련 일시정지 토글, 세션 메모 입력 후 '훈련 일지 저장하기' 클릭.
- 확인할 조건: 훈련 메모 입력값이 비어있는지 여부, 드릴 체크 박스 선택 개수, 메모 목록 삭제 버튼 클릭 여부.
- 분기별 반응:
- 성공 반응: 드릴 체크 시 진행률(%) 즉시 업데이트, 메모 입력 후 저장 시 하단 리스트에 항목 추가 및 카운트(+1) 증가.
- 오류 반응: 메모가 비어있을 경우 "메모 내용을 입력해 주세요." 경고 표시 및 입력창 강조·포커스.
- 취소/삭제 반응: 저장된 일지의 '삭제' 버튼 클릭 시 해당 메모 제거 및 카운트 감량.
- 상태 유지/복귀: '완료 화면으로 돌아가기' 클릭 시 입력했던 설정 및 작성 일지 상태 유지.
- 다음 행동: 추가 메모 작성 또는 '처음 설정으로 돌아가기'를 통한 훈련 전체 재설정.

## 3. 직접 시험(Test) 결과
- 정상 경로: [Step 4]에서 시작 버튼 클릭 시 이전 단계에서 작성한 훈련 제목과 시간이 [Step 5] 상단에 정상 반영됨.
- 오류 검증: 메모 입력창을 비운 채 저장 시 오류 메시지 출력 및 입력창 포커스 이동 확인.
- 상태 변경/삭제: 드릴 체크박스 클릭 시 진행률이 0% -> 33% -> 67% -> 100%로 변경되며, 작성한 메모 삭제 시 목록에서 정상 제거됨.
- 모바일 반응형: 375px 화면 너비에서 타이머 및 버튼 레이아웃이 겹침 없이 수직 배치로 정상 동작함.
