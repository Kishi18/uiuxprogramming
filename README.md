# How to improve at basketball - 농구 스킬 향상

## 사용자와 목표
- 사용자 : 농구를 입문하거나 실력 향상을 목표로 하는 사람[cite: 4]
- 목표 : 기본적인 훈련 루틴을 정하고, 향상을 위한 연습을 한다.[cite: 4]

## 1. 이번 주 추가·수정한 기능
- **서비스 맞춤형 내비게이션 개편**: 수업 예제(발표 훈련) 대신 농구 스킬 트레이닝 서비스에 맞춘 주요 메뉴 3종(`nav > ul > li`)을 구성하고 각 섹션으로 연결했습니다.
- **현재 위치 표시 및 상태 동기화**: 활성 메뉴가 시각적으로 구분되도록 스타일을 적용하고 `aria-current="page"`를 부여했습니다(비활성 메뉴에서는 제거). 메뉴 이동, 페이지 새로고침, 브라우저 뒤로 가기(`hashchange`) 이후에도 현재 위치 표시가 실제 화면과 일치합니다.
- **목록 필터링 및 결과·빈 상태 안내**: 훈련 루틴 목록을 종목 및 완료 상태별로 골라 볼 수 있는 필터를 추가하고, 선택 상태를 `aria-pressed`에 반영했습니다. 현재 표시되는 항목 수를 안내하며, **[전체 루틴이 없는 경우]**와 **[선택한 조건에 맞는 결과만 없는 경우]**를 구분해 안내 문구를 출력합니다.
- **모바일 메뉴 구현**: 600px 이하 좁은 화면에서 `메뉴 열기` / `메뉴 닫기` 버튼을 통해 메뉴를 펼치거나 접을 수 있도록 구현했습니다. 펼침 여부에 따라 실제 표시 상태, 버튼 문구, `aria-expanded` 값이 함께 변경되며, 목적지 선택 시 이동과 동시에 메뉴가 닫힙니다.

## 2. 메뉴별 목적지
- **훈련 가이드 (`#about`)**: 훈련 정보 입력 → 훈련 강도 설정 → 저장 및 관리로 이어지는 3단계 이용 방법 안내 섹션으로 이동
- **루틴 만들기 (`#planner`)**: 훈련 루틴 이름, 종목(드리블·슈팅·피지컬), 중점 포인트, 목표 시간 및 달성 기준을 입력해 새 루틴을 저장하는 영역으로 이동
- **내 훈련 루틴 (`#archive`)**: 저장된 훈련 루틴 목록을 조회하고 필터링하며, 루틴 상세 보기 및 완료 상태를 관리하는 영역으로 이동

## 3. 목록 필터 기준
- **전체 (`all`)**: 저장된 모든 농구 훈련 루틴 표시
- **드리블 (`dribble`)**: 볼 핸들링·크로스오버 등 드리블 종목 루틴만 표시
- **슈팅 (`shooting`)**: 캐치앤슛·풀업·자유투 등 슈팅 종목 루틴만 표시
- **피지컬 (`physical`)**: 풋워크·민첩성·컨디셔닝 등 피지컬 종목 루틴만 표시
- **훈련 완료 (`completed`)**: 훈련을 마치고 완료 처리한 루틴만 표시

## 4. 기능을 확인할 수 있는 조작 순서
1. **메뉴 이동 및 현재 위치 동기화 확인**
   - 상단 메뉴(`훈련 가이드` → `루틴 만들기` → `내 훈련 루틴`)를 차례로 클릭해 활성 메뉴 강조 표시(`aria-current="page"`) 변화를 확인합니다.
   - 페이지 새로고침(F5) 및 브라우저 뒤로 가기 버튼을 눌러 현재 위치 표시가 화면 위치와 일치하는지 확인합니다.
2. **루틴 등록 및 기존 기능 유지 확인**
   - `루틴 만들기`에서 서로 다른 종목(예: `드리블`, `슈팅`)의 훈련 루틴을 2개 이상 입력·저장합니다.
   - `내 훈련 루틴`에서 `루틴 상세` 모달 열기와 `훈련 완료 체크` 토글이 정상 작동하는지 확인합니다.
3. **목록 필터 및 빈 결과 안내 확인**
   - `전체`, `드리블`, `슈팅`, `피지컬`, `훈련 완료` 버튼을 차례로 클릭하며 버튼의 선택 상태(`aria-pressed`)와 상단 루틴 개수(`#plan-count`) 변경을 확인합니다.
   - 등록되지 않은 종목(예: `피지컬`)을 선택했을 때와 전체 루틴을 모두 비웠을 때의 빈 화면 안내 문구가 구분되어 표시되는지 확인합니다.
4. **모바일 반응형 메뉴 확인**
   - 브라우저 개발자 도구(F12)에서 모바일 화면 너비(예: 375px)로 전환한 뒤, 상단 `메뉴 열기` 버튼을 눌러 메뉴 펼침·닫힘 및 버튼 문구(`메뉴 닫기` ↔ `메뉴 열기`), `aria-expanded` 변경을 확인합니다.
   - 펼쳐진 상태에서 메뉴 항목을 클릭해 해당 섹션으로 이동하면서 메뉴가 자동으로 닫히고 콘텐츠와 겹치지 않는지 확인합니다.
