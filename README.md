# HoopLab (How to improve at basketball - 농구 스킬 트레이닝 계획)

## 1. 서비스명 및 간단한 소개
- **서비스명**: HoopLab (농구 스킬 트레이닝 계획)
- **소개**: 농구를 입문하거나 개인 실력 향상을 목표로 하는 사용자가 훈련 종목(드리블·슈팅·피지컬), 목표 시간, 목표 달성 기준을 설정해 나만의 훈련 루틴을 설계·보관하고 코트에서 완료 여부를 관리하는 웹 애플리케이션입니다.

## 2. 11주차 웹 접근성 개선 내용 (개선 전 → 개선 후)

1. **본문 바로가기(Skip Link) 제공 및 키보드 진입 구조 개선**
   - **개선 전**: 키보드 사용자가 페이지에 접속하면 상단 로고, 메뉴 열기, 주요 메뉴, 테마 전환 버튼을 모두 거쳐야 본문 콘텐츠로 이동할 수 있었습니다.
   - **개선 후**: 문서 최상단(`<body>` 직후)에 `본문 바로가기` 링크(`.skip-link`)를 추가하고 `<main id="top" tabindex="-1">`로 연결했습니다. 첫 `Tab` 키 입력 시 좌측 상단에 링크가 나타나며 `Enter` 키로 본문 영역에 즉시 초점을 이동할 수 있습니다.

2. **선택 상태의 다중 시각 단서 제공 (색상 + 굵기 + 밑줄)**
   - **개선 전**: 현재 선택된 상단 메뉴(`.is-current`)와 목록 필터 버튼(`.is-active`)이 글자색과 배경색 변화만으로 구분되어 색약·저시력 사용자가 인지하기 어려웠습니다.
   - **개선 후**: `aria-current="page"` 및 `aria-pressed="true"` 상태의 요소에 굵은 글씨(`font-weight: 800`)와 밑줄(`text-decoration: underline; text-underline-offset: 6px`) 스타일을 함께 적용해 색상 외 시각적 단서로도 선택 상태를 명확히 구분할 수 있도록 개선했습니다.

3. **브라우저 탭 제목 동기화 및 대화상자·입력 안내 접근성 개선**
   - **개선 전**: 상단 메뉴를 이동해도 브라우저 탭 제목이 고정되어 현재 위치를 파악하기 어렵고, 상세 모달의 닫기 버튼이 단순 `닫기`로만 안내되며, 글자 수 카운터가 입력할 때마다 불필요한 음성 알림을 발생시켰습니다.
   - **개선 후**: 메뉴 이동 및 뒤로 가기(`hashchange`) 시 활성 메뉴명을 반영해 브라우저 탭 제목이 `루틴 만들기 | HoopLab` 형태로 동적 변경되도록 구현했습니다. 또한 상세 모달 닫기 버튼에 `aria-label="훈련 루틴 상세 닫기"`를 부여하고, `#title-count`의 불필요한 `aria-live` 속성을 제거해 입력 방해를 줄였습니다.

4. **모바일 메뉴 `Esc` 키 닫기 및 목록 필터·초점 복귀 강화**
   - **개선 전**: 600px 이하 모바일 화면에서 펼쳐진 메뉴를 키보드로 닫으려면 토글 버튼까지 다시 이동해야 했으며, 필터링 상태에서 루틴 완료 처리로 카드가 목록에서 사라지면 초점 위치가 유실되었습니다.
   - **개선 후**: 모바일 메뉴가 열린 상태에서 `Escape` 키를 누르면 즉시 메뉴가 닫히고 `메뉴 열기` 버튼으로 초점이 복귀하도록 구현했습니다. 아울러 필터 선택 시 표시 개수를 문장으로 안내하고, 카드 상태 변경으로 해당 카드가 사라지면 현재 선택된 필터 버튼으로 초점을 되돌리며, 결과가 0건일 때는 `전체 보기` 버튼을 제공해 키보드로 즉시 전체 목록에 복귀할 수 있습니다.

## 3. 접근성 및 동작 검증 결과
- **정상 경로**: 첫 `Tab` 키로 `본문 바로가기` 진입 → `루틴 만들기`에서 종목·시간 입력 및 저장 → `내 훈련 루틴`에서 종목별 필터(`드리블`, `슈팅`, `피지컬`, `훈련 완료`) 선택 시 탭 제목, 밑줄, 결과 개수 안내 문구가 모두 일치함을 확인했습니다.
- **예외 및 키보드/모바일 검증**: 빈 제목 제출 시 오류 문구 출력 및 입력창 초점 이동, 375px 모바일 화면에서 `Enter`로 메뉴 펼침 후 `Esc` 키 닫기 및 토글 버튼 초점 복귀, 필터 결과 0건 상태에서 `전체 보기` 실행 시 전체 루틴 복귀 동작을 확인했습니다.
